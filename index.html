账目交换

通过文件把 Windows 和 iPhone 的账本连接起来。

① 导入 Windows 账单

支持 Windows MyLedger 导出的 CSV（包含日期、类型、金额、类别、支付方式、备注）。先预览，再确认导入。

② 导出给 Windows

导出兼容 Windows MyLedger 的 UTF-8 CSV；在 Windows 版“流水明细 → 导入历史账单 CSV”即可导入。

双向交换是手动文件传递，不是实时自动同步；修改过的同一笔交易可能产生冲突或重复，请核对。

③ 完整备份与恢复

JSON 备份保留手机端交易唯一编号，适合原样恢复本设备记录。建议定期保存到 iPhone“文件”App。
